# Outpost Zero

A tiny browser-playable base-building and defense game. Built with vanilla HTML, CSS and JavaScript — no backend, build step, external dependencies or hosting service required.

## Play locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow that publishes the site from the `main` branch. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions** if it is not already selected. The workflow will deploy on each push to `main`.

Your game URL will be:
`https://RijonBD.github.io/mini-strategy-game/`

## Gameplay
- Passive credits arrive every few seconds.
- Build generators to supply power before adding powered structures.
- Supply depots and alloy works produce resources.
- Build turrets and train infantry to defend against escalating waves.
- Save progress in your current browser with the Save button.

Progress is stored locally in the browser and does not sync between devices.
