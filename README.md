# OUTPOST ZERO — Phaser 3 Survival Shooter

A mobile-friendly 2D top-down survival shooter built with TypeScript, Phaser 3 and Vite. GitHub Pages hosts the compiled static site; no game server or separate hosting is required.

## Controls
- Mobile: left virtual joystick to move, hold FIRE to shoot (nearest-enemy auto-aim).
- Desktop: WASD or arrow keys to move, hold Space to fire, R to reload.

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
``
The deployable static site is generated in `dist/`.
